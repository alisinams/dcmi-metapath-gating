# Raw data

This folder receives the raw benchmark files; they are not part of the repository.

    python code/download.py      # data/ml-100k, data/ml-1m, data/lastfm (GroupLens)
    python code/dl_amazon.py     # data/amazon (Amazon Reviews 2023, Video Games)

The datasets remain under the terms of their distributors. MovieLens: https://grouplens.org/datasets/movielens/ ;
HetRec 2011 Last.FM: https://grouplens.org/datasets/hetrec-2011/ ; Amazon Reviews 2023: https://amazon-reviews-2023.github.io/
